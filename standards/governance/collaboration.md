# Collaboration governance standard

Gate algorithms and retry limits are built into ZipZap. Project standards provide only project-specific applicability, verification commands, high-risk areas, and human authority boundaries.

Feedback is deduplicated by fingerprint. Two independent Git Checkpoints may trigger a standards-improvement proposal; a high-risk problem item may trigger one immediately. Never create an append-only feedback database, auto-edit `AGENTS.md`, or append a duplicate rule. Merge or revise the narrowest existing standard after human review. A repeated bootstrap-routing gap may propose, but never apply, a minimal `AGENTS.md` revision.
